However accurate a subsidence map is, if it only lives on the computer of the person who made it, it hasn't helped anyone yet. WebGIS is the bridge that brings spatial data to end users, and all they need is a web browser.

## What I do

- Develop WebGIS applications based on Python and R.
- Build interactive map interfaces for raster and vector data with Leaflet and MapLibre.
- Serve data through GeoServer using the WMS, WFS and WMTS standards.
- Optimise rendering and the user experience, making sure everything runs smoothly on phones too.
