Processing remote sensing imagery usually involves a lot of repetitive steps: downloading the images, applying corrections, clipping them to the area of interest, computing indices and exporting maps. Doing a few images by hand is fine, but once the data grows to hundreds of scenes, you need a workflow that runs automatically.

## What I do

- Write tools that automate the processing of remote sensing imagery and geospatial data.
- Use parallel processing so that many image scenes run at the same time.
- Research, design and develop automated workflows for new problems.

## Tools

Python, NodeJS, JavaScript and TypeScript, together with image processing and GIS libraries.
